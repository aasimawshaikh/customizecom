# Customer Web App

Planned stack: React, Vite, TypeScript.

Primary journey:
1. Select occasion and recipient.
2. Enter recipient name, preferences, mood, and budget.
3. Build a hamper from eligible catalogue items.
4. Select a compatible box and packaging.
5. Add a physical message and optional digital greeting.
6. Review the verified total and complete checkout.

No standalone product checkout and no ready-made hamper purchasing.

Implementation has not started yet.
